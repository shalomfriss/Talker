# Open Voice

Open Voice is an offline-first AAC app for iPhone and iPad. It helps a person build a message with picture buttons or typing, speak it aloud, show it at large size, and share it. No account or network connection is required for the current features.

## Build and run

Requirements: Xcode 27, iOS 26 simulator or device, and [XcodeGen](https://github.com/yonaskolb/XcodeGen). Xcode resolves the [ZIPFoundation](https://github.com/weichsel/ZIPFoundation) package for Open Board Format archives on the first build.

```sh
xcodegen generate
xcodebuild -project OpenVoice.xcodeproj -scheme OpenVoice -sdk iphonesimulator -configuration Debug -destination 'generic/platform=iOS Simulator' build CODE_SIGNING_ALLOWED=NO
# Select an installed simulator UUID for tests:
xcodebuild -project OpenVoice.xcodeproj -scheme OpenVoice -destination 'platform=iOS Simulator,id=YOUR_SIMULATOR_UUID' -collect-test-diagnostics never test
```

Open `OpenVoice.xcodeproj` in Xcode to run on an iPhone or iPad. Personal device installation requires a development team selected in Xcode.
