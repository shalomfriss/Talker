# Open Board Format fixtures

These examples come from the [Open Board Format example collection](https://www.openboardformat.org/examples):

- `openboard-simple.obf`: `https://openboards.s3.amazonaws.com/examples/simple.obf`
- `openboard-links.obz`: `https://openboards.s3.amazonaws.com/examples/links.obz`
- `openboard-media.obz`: `https://openboards.s3.amazonaws.com/examples/images_and_sounds.obz`

The files exercise numeric button IDs, linked boards, and photo/audio paths in independent Open Board Format exports.
